# ayuclips

A browser-based video clipping tool for preparing shorter segments from longer videos. The interface supports selecting a source video and lists MP4, MOV, and WEBM as supported input types.

## Open locally

Open `index.html` in a modern browser, or serve the project over HTTP:

    python -m http.server 8000

Visit http://localhost:8000.

## Working with video

Test with a short sample first and check that the browser can decode the selected format. Verify the implementation and browser behaviour before relying on privacy or performance claims for large videos.
